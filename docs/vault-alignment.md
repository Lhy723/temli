## M19 验收口径

- 标签：保存/索引后进入标签表；面板按使用次数排序；点击标签过滤列表。
- 附件：≤25 MB，文件名清洗，落到 `attachments/`；编辑器粘贴/选择文件后插入 `![](attachments/…)`；预览能显示图片。
- 模板：`templates/*.md` 出现在新建对话框；`{{date}}`/`{{time}}`/`{{title}}` 替换。
- 属性：键值编辑保存后 frontmatter 正确，正文不变；非法/保留键拒绝。
- 日记：生成当日文件，已存在则直接打开。
- 大纲：解析 ATX 标题，点击滚动到对应行。
- 快速切换与 `[[` 补全：键盘上下选择、回车打开、Esc 关闭。
- 重命名：更新全库 `[[旧标题]]` / `[[旧标题|别名]]`，不误改代码块内文本（尽力而为，文档注明）。
